The last text message a dying phone sends at one percent battery, in the phone's own voice: a deathbed confession that it never actually charged past 97% — it just liked watching its owner panic.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only) writes the single message to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The text is under 200 characters, as the bounty requires.
